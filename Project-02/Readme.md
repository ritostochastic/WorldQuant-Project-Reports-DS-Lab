# Project 2: Predicting Housing Prices in Buenos Aires with Linear Regression

An applied machine learning project focused on analyzing residential property listings and predicting housing prices in Buenos Aires, Argentina.

## Project Overview

This project explores the relationship between property characteristics, location, and residential property prices. It applies data cleaning, exploratory data analysis, and linear regression techniques to develop and evaluate housing price prediction models.

## Workflow

### 1. Data Preparation
- Imported and cleaned real estate listing data.
- Examined missing values and inconsistencies in property attributes.
- Prepared numerical and categorical variables for modeling.

### 2. Exploratory Data Analysis
- Investigated housing price distributions.
- Examined relationships between property size, location, and listing prices.
- Explored geographic variation in property valuations.

### 3. Regression Modeling
- Established a Linear Regression baseline.
- Explored Ridge (L2) and Lasso (L1) regularization.
- Examined how regularization affects model coefficients and predictive performance.

### 4. Model Evaluation
- Compared model performance using appropriate regression metrics.
- Considered the trade-off between model complexity and predictive accuracy.

## Key Takeaways

- Property characteristics and geographic location are important considerations in housing price modeling.
- Regularization provides a way to control model complexity and reduce the risk of overfitting.
- The project demonstrates an applied regression workflow, from data preparation to model evaluation.
