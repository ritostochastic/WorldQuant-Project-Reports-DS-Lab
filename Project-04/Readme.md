# Project 4: Predicting Earthquake Damage in Nepal with Classification Models

A supervised machine learning project focused on predicting building damage following the 2015 Gorkha earthquake in Nepal.

## Project Overview

Understanding the factors associated with structural damage can help inform disaster preparedness and reconstruction planning.

This project uses building-related data to investigate the relationship between structural characteristics and earthquake damage categories. Classification models are applied to predict the level of damage sustained by buildings.

## Workflow

### 1. Data Preparation
- Prepared building survey data for supervised learning.
- Examined structural and construction-related variables.
- Processed categorical and numerical features for modeling.

### 2. Exploratory Analysis
- Investigated the distribution of damage categories.
- Examined relationships between building characteristics and observed damage.

### 3. Classification Modeling
- Developed classification models to predict building damage categories.
- Explored the ability of different model architectures to capture relationships between structural characteristics and damage outcomes.

### 4. Model Evaluation
- Evaluated classification performance using suitable classification metrics.
- Examined prediction errors across damage categories.

## Key Takeaways

- Building characteristics provide useful information for understanding structural vulnerability.
- Classification models can help identify patterns associated with different levels of earthquake damage.
- Model evaluation should consider performance across all damage categories, rather than relying solely on overall accuracy.
