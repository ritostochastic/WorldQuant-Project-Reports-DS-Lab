# Project 3: Time Series Modeling of Air Quality in Nairobi

A time series analysis project focused on understanding and modeling air quality measurements in Nairobi, Kenya.

## Project Overview

Air quality measurements often exhibit temporal patterns, making time series techniques useful for understanding their behavior and forecasting future observations.

This project applies time series analysis to air quality data, examining temporal dependencies and developing forecasting models.

## Workflow

### 1. Data Preparation
- Prepared air quality observations for time series analysis.
- Examined timestamps, missing observations, and data consistency.
- Organized measurements into a suitable temporal structure.

### 2. Exploratory Time Series Analysis
- Investigated trends and temporal patterns.
- Examined autocorrelation and partial autocorrelation.
- Assessed stationarity as part of model selection.

### 3. Time Series Modeling
- Explored autoregressive and related time series modeling techniques.
- Investigated how past observations can help explain future air quality measurements.

### 4. Model Evaluation
- Evaluated forecasting performance using time-aware validation.
- Considered model performance against a baseline forecasting approach.

## Key Takeaways

- Air quality data can contain temporal dependencies that are useful for forecasting.
- Stationarity and autocorrelation diagnostics help guide time series model selection.
- Time-aware evaluation is important when assessing forecasting models.
